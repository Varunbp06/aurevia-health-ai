## ⚡ Quick Start

### 1. Clone and Install

```bash
# Clone the repository
git clone https://github.com/varunbpvarunbp/aurevia-health-ai.git
cd aurevia-health-ai

# Install Python dependencies
python -m pip install -r requirements-full.txt

# Install frontend dependencies
cd frontend
npm install
cd ..
```

### 2. Configure Environment Variables

```bash
# Copy the example environment file
cp .env.example .env

# Edit .env with your configuration
# Required: DATABASE_URL, SECRET_KEY, GOOGLE_API_KEY (for Gemini)
# Optional: OLLAMA_BASE_URL, OLLAMA_MODEL, GEMINI_MODEL
```

### 3. Initialize Database

```bash
# Run database migrations and seed mock data
python scripts/run_clinical_demo.py
```

### 4. Start Development Servers

```bash
# Terminal 1: Backend
python -m uvicorn backend.main:app --host 0.0.0.0 --port 8000

# Terminal 2: Frontend
cd frontend
npm run dev
```

### 4. Access the Application

- **Frontend**: http://localhost:3000
- **Backend API**: http://localhost:8000
- **API Documentation**: http://localhost:8000/docs
- **Health Check**: http://localhost:8000/healthz

### Optional: Local LLM (Ollama)

```bash
# Install Ollama
curl -fsSL https://ollama.com/install.sh | sh

# Pull models
ollama pull llama3.2
ollama pull nomic-embed-text
```
